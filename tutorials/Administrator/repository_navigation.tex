# RIT Dynamic Room Reservation System (DRRS) - Repository Map

This document provides a comprehensive map of the repository structure for the Dynamic Room Reservation System (DRRS) project, designed to help new developers quickly understand the codebase organization and navigate the project effectively.

## Project Overview

The Dynamic Room Reservation System is a web-based platform that allows students, faculty, and staff at RIT to reserve rooms across campus. The system provides real-time availability information, interactive maps, and booking management features.

## Technology Stack

- **Frontend**: React with Material UI
- **Backend**: Firebase (Authentication, Firestore Database, Hosting)
- **State Management**: React Context API
- **Maps/Visualization**: Custom implementation with SVG floor plans

## Repository Structure

### Root Directory

```
/
├── public/                   # Static files and assets
├── src/                      # Source code 
├── .firebase/                # Firebase cache and deployment files
├── .github/                  # GitHub workflows for CI/CD
├── Project Roadmap.docx      # Project documentation
└── Vision Statement.pdf      # Project vision document
```

### Configuration Files

- **`.firebaserc`**: Firebase project configuration identifying the project ID
- **`firebase.json`**: Main Firebase configuration specifying hosting settings
- **`package.json`**: Project dependencies and npm scripts
- **`firestore.rules`**: Security rules for Firestore database
- **`storage.rules`**: Security rules for Firebase Storage
- **`firestore.indexes.json`**: Firestore index configurations
- **`database.rules.json`**: Rules for Firebase Realtime Database

### Source Code Structure (`src/`)

#### Core App Files

- **`src/index.js`**: Entry point that renders the React app with Auth provider
- **`src/App.js`**: Main component with routing configuration
- **`src/App.css`** & **`src/index.css`**: Global styling
- **`src/theme.js`**: Material UI theme configuration with RIT branding colors
- **`src/reportWebVitals.js`**: Performance monitoring

#### Firebase Configuration

- **`src/firebase/config.js`**: Firebase SDK initialization and exports

#### Context Providers

- **`src/contexts/AuthContext.js`**: Authentication context with user state management

#### Services

- **`src/services/roomService.js`**: Room and reservation management functions
- **`src/services/userService.js`**: User data and hour request management
- **`src/services/analyticsService.js`**: Analytics data collection and processing
- **`src/services/mapService.js`**: Map visualization services and building/floor information

- **`src/pages/RoomDetails.js`**: Detailed information about a specific room
- **`src/pages/AdminPage.js`**: Admin dashboard with analytics and management tools

## Core Features

1. **Room Search & Booking**
   - Find rooms by time, capacity, equipment, building
   - Multiple view modes (list, schedule, map)
   - Book rooms with collaborative invitations

2. **Interactive Maps**
   - Building and floor selection
   - Real-time room availability visualization
   - Room details accessible from the map

3. **Reservation Management**
   - View upcoming, today's, and past reservations
   - Cancel or modify bookings
   - Daily booking limits with extension requests

4. **Admin Features**
   - Analytics dashboard with usage metrics
   - Room management tools
   - User hour request approval system
   - Report generation and export

## Development Workflow

1. The app uses React Router for navigation between pages
2. Authentication state is managed through the AuthContext
3. Firebase services are accessed through dedicated service modules
4. Room data and reservations are stored in Firestore collections
5. Continuous deployment is handled through GitHub Actions workflows

## Getting Started for New Developers

1. Clone the repository
2. Run `npm install` to install dependencies
3. Create a `.env` file with Firebase configuration (ask team lead for details)
4. Run `npm start` to start the development server
5. For admin access, your email needs to be added to the `admin` collection in Firestore
